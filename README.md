## Run locally

Requirements: Node.js 22 or later, npm, and Git.

```bash
git clone https://github.com/pyatrick666/Professional-Portfolio.git
cd Professional-Portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). To create a production build, run `npm run build`.
