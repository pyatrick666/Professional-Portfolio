# Pratik Poudel — Professional Portfolio

A personal developer portfolio built with **Next.js and TypeScript**, presented through a Visual Studio Code-inspired interface. It showcases my background, technical skills, projects, GitHub activity, and ways to get in touch.

My interests include:

- Full-stack web development
- Mobile application development
- Software engineering
- Networking and computer systems
- UI/UX and digital design

I’m currently building practical projects while developing my skills for future software development, full-stack, networking, and technology internships.

## ✨ Features

- VS Code-inspired portfolio interface
- Responsive layout for desktop and mobile
- Interactive navigation and editor-style tabs
- Personal introduction and education information
- Technical skills and development stack
- Featured projects
- GitHub repository and contribution information
- Interactive terminal-style section
- Contact and social links
- Resume access
- Dark developer-focused visual design
- GitHub Pages deployment through GitHub Actions
