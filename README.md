## Overview

I’m Pratik Poudel, a BSc (Hons) Information Technology — Computer Systems Engineering student at ISMT College.

This portfolio presents my work through an interactive dirt-bike inspired 3D environment, combining professional content with real-time web graphics.

## Tech Stack

- **HTML5** — Structure and content
- **CSS3** — Layout, styling, and responsive design
- **JavaScript** — Application logic and interaction
- **Three.js** — Real-time 3D rendering
- **WebGL** — Browser-based graphics
- **GitHub Pages** — Deployment

## Key Features

- Interactive Three.js environment
- Procedurally generated dirt bike and terrain
- Keyboard, mouse, and touch interaction
- Jump, landing, and suspension effects
- Rain, fog, particles, and dynamic lighting
- Responsive interface
- WebGL fallback for unsupported environments

## Local Development

Clone the repository and run it with a local web server:

```bash
git clone https://github.com/pyatrick666/Professional-Portfolio.git
cd Professional-Portfolio
python3 -m http.server 8000
```

Open **http://localhost:8000** in your browser.

## Controls

| Input | Action |
|---|---|
| W / ↑ | Move forward |
| S / ↓ | Move backward |
| A / ← | Turn left |
| D / → | Turn right |
| Mouse drag | Look around |
| Enter | Start the ride |
| Trail markers | Navigate sections |
